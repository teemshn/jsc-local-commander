# PROJECT_SPEC — ChatGPT 명령 기반 Windows 문서·도면 작업

상태: 2026-11-20 설계안 / 실제 고객 문서에 적용 전 / G0·G1 선행

## 1. 문제와 성공 정의
목적: 사용자가 PC 앞에 없을 때도 휴대폰의 ChatGPT 대화에서 '계약서 표기 수정', '내역서 수식 재계산', 'DWG 객체 이동', '결과물 PDF' 등을 지시하고, 필요한 Windows 앱을 이용해 수정본과 검증 결과를 받는다. PC에서 같은 대화·승인 경로를 이용할 수 있어야 한다.

완료의 정의: 승인된 대상·범위 내 변경만 반영, 원본과 기존 열린 작업 보존, 작업의 재현·취소·감사 가능, 모바일에서 실행 및 결과 조회 실증. 단순한 커맨드 성공/화면 클릭으로 '완료' 표시 금지.

## 5. 비기능 요구와 안전 수치
수치는 실험 시 조정할 **초기 제안값**이며 이미 보장되는 기능 아님.
- 동시 GUI 작업: PC/세션당 최대 1개; 동일 파일 동시 변경 금지.
- 시간: GUI 작업 60초 기본·상한 180초(명시된 단계 별), Excel 단일 편집 20초 상한부터 시작. 초과 시 안전중단/증거 기록.
- 호출/요청: 대기열 10개 이내, 재연결 횟수 최대 3회, *쓰기 작업 재시도 0회*.
- 자원: 작업 전 디스크·RAM 사전점검, 성능 이상 시 중단. 사용자 승인·장치별 한도는 실기기 검증 후 확정.
- 출력·스크린샷: 민감정보 최소화, 결과 크기 제한, 개인정보 마스킹, 명시적 보존기간.
- 장애: 후속 요청을 계속 처리할 수 없는 경우 기능 전체를 안전 잠금.
- 비용: 추가 유료 인프라 전제 금지, 필요한 외부 서비스 요금·계정 권한 확인 후 결정.

## 6. 역할
- 요청자: ChatGPT에서 작업 계획 요청; 원격 발화가 곧 OS 작업 승인은 아님.
- 승인자: 독립 로컬/검증된 안전 채널에서 행위·파일·대상·변경전후를 명시적으로 승인.
- Broker: OS 권한/정책/자원/중복/백업 검사, 제한 워커 제어.
- GUI/API Worker: 등록된 앱별 작업만, 사용자 세션에서 제한된 명령 수행.
- 운영자: 재부팅/실패 사고 복구/정책 변경. AI 임의로 복구 상태 해제 불가.

## 7. 설계 결정 대기
- 실제 업무용 Windows 계정과 잠금 화면 정책/전용 세션 가능 여부.
- CAD 제품명/에디션/버전, HWP 버전/상업적 라이선스, Excel 버전.
- 현재 계정/워크스페이스에서 모바일 사용자 정의 MCP 쓰기 호출 지원 여부.
- 실제 수정 허용 폴더·고객정보 등급, 결과물 저장 드라이브/기간.
- 원격 승인 UI의 안전 채널과 2차 인증.
- WSL2/Ubuntu가 실제로 필요한 Linux 전용 컴포넌트가 있는지.

미확정 항목은 자동 추정하거나 기본 권한으로 활성화하지 않는다.
