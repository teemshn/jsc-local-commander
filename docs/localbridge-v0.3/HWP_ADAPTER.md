# HWP/HWPX Adapter 설계 + 디버그 시나리오

상태: DESIGN ONLY — COM 등록이 확인돼도 자동화 API 호출·저장 검증까지 성공했다는 뜻이 아님.

## HWP-1. 목표
Windows 설치 한글(HWP) 프로그램으로 합성 계약서의 특정 본문/표 셀·문단을 변경하고, 원본을 보존한 채 새 HWP 또는 HWPX로 저장. 텍스트와 문단/스타일/표/머리말·꼬리말/쪽나눔/인쇄 결과를 비교한다. 실제 법적 계약서나 날인·도장 파일은 별도 고위험 승인 전에는 수정하지 않는다.

## HWP-2. 사용 인터페이스 우선순위
1. 실제 설치된 한글의 제품/비트수/버전 확인, 공식 HwpObject COM Automation 및 HAction/ParameterSet으로 기능 조사.
2. 구조화된 문서 이벤트/찾아바꾸기/북마크·누름틀·셀 커서 조작 등 버전별 정식 API 사용 가능 여부 실기기 확인.
3. API 미지원 작업은 전용 사용자 세션 Windows UI Automation 레시피, 화면·선택 범위 재확인 후 보조 수행.
4. 문자·표가 아닌 페이지 시각 비교는 필요시 프로그램 자체 PDF 인쇄/미리보기로 검증. PDF 저장 성공만으로 원본 서식 일치 보증 불가.

공식 근거: https://developer.hancom.com/en-us/hwpautomation
한컴 공식 페이지에는 외부 로컬파일 접근 시 보안 승인 메시지가 나타날 수 있고, 파일경로 검증 모듈 및 상업 사용 관련 별도 라이선스 안내가 있음. 이를 일괄 무시하거나 비공식 우회해서는 안 됨. 회사 사용·사내 배포가 라이선스 적용 대상인지 사용 목적별로 확인한다.

## HWP-3. 제한 도구 (제안)
- inspect_hwp_document: 문서 정보/표/누름틀/문단·페이지 목록(민감 내용 최소 출력).
- plan_hwp_replace: 대상 문구+문맥/위치/예상 매칭 건수, 범위, diff, 리스크를 예고.
- apply_hwp_copy_edit: 승인된 정확한 한 위치만 변경, 신규 파일로 저장.
- verify_hwp_artifact: 새 파일 재열기, 이전 문구/신규 문구·표 셀/서식/쪽수·출력 확인.

입력: source_id, source_hash, expected_format(HWP/HWPX), anchor(문단/북마크/누름틀/표 좌표), expected_text, replacement_text, match_count=1, output_name, approval_plan_hash.
원격 실행 문자열/COM 메서드 이름/미리 검증되지 않은 Action 이름은 입력받지 않는다.

## HWP-4. 실행 계획
1. 복사본 생성 전 원본 경로·file_id·SHA256 및 문서 비밀/서명·읽기전용 여부 확인.
2. HwpObject COM 시작. 프로세스 ID와 창·사용자 세션이 현재 다른 문서를 편집 중인지 확인. 기존 사용자 문서에 결합 금지.
3. 새 시험용 문서를 읽기 전용 열기, 표·북마크·누름틀/텍스트 위치 등 앵커를 추출.
4. 예상 문구를 단 한 곳에서 찾아 범위·본문/표 구분 및 정확 매칭 검증.
5. 계획한 텍스트만 변경하되 스타일/탭/셀 병합/글자 크기/줄바꿈을 불필요하게 변경하지 않는다.
6. 신규 이름으로 SaveAs, 재열기, 변경문구·문서 구조·출력물 비교. 도장·개인정보 포함된 캡처는 최소화.
7. 워커 및 작업용 한글 프로세스만 정리. 승인된 수정본만 반환, 실패 시 수동 검토 상태.

## HWP-5. 디버그 케이스
| ID | 유발 조건 | 반드시 확인할 사항 | 실패 동작 / 통과 기준 |
|---|---|---|---|
| HWP-D01 | HWP 오토메이션 CLSID는 있으나 실행 COM 실패 | 비트수/제품 버전/ProgID/프로세스 | 지원 불가로 표시, 설치 수정 금지 |
| HWP-D02 | 보안 경고/파일경로 모듈 인증 문제 | 경고 메시지/모듈 서명/등록/승인 상태 | 무단 우회 금지, 사용자 확인 없으면 중단 |
| HWP-D03 | HWP ↔ HWPX 변환 중 구조 차이 | 저장 포맷/인쇄 레이아웃/각주/표 | 기존 포맷 유지, 손실 시 결과 거부 |
| HWP-D04 | 찾을 문구가 중복 존재 | 문맥·매칭 수·북마크 | 1건이 아니면 거부 |
| HWP-D05 | 문서의 표/셀 이동·병합 | 표 번호/행·열/셀 텍스트/병합상태 | 예상 좌표와 다르면 중단 |
| HWP-D06 | 선택된 블록/IME 입력으로 다른 텍스트 삭제 | selection/caret, before/after text | 대상 밖 변경 0건 |
| HWP-D07 | 쪽나눔/문단/글꼴/자간 변화 | 스타일 ID/쪽 수/PDF 비교 | 시각 차이 검토 필요, 자동 완료 금지 |
| HWP-D08 | 머리말·꼬리말·각주·누름틀 누락 | 문서 영역 목록 | 기능 미지원이면 수동 검토 |
| HWP-D09 | 도장·이미지·표시 인증 인감 변경 | 객체 수/파일 해시/디자인 검토 | 원본 변경 금지, 변경 시 강력 승인 |
| HWP-D10 | 프로그램 팝업/자동 복구창 | 활성 HWND/종료 시 창 | 미인식 팝업이면 중단, 무작정 Enter 금지 |
| HWP-D11 | 파일이 열린 상태/읽기전용/암호 | 소유 PID/파일 잠금/보안 상태 | 별도 사본, 실패 시 원본 불변 |
| HWP-D12 | 한글 실행·저장이 느리거나 멈춤 | timeout/heartbeat/전용 PID | 워커 제한 시간 후 중단, 자동 재시도 0 |
| HWP-D13 | COM 종료 후 한글 프로세스 잔류 | owned_pid vs user_pid | 소유 검증된 시험 프로세스만 정리 |
| HWP-D14 | 다른 언어/인코딩·특수문자 | 문자 정규화/수정 전후 | 한글·기호·수식 정확 일치 |
| HWP-D15 | 상업 배포 라이선스 불확실 | 사용목적/라이선스 문서 버전 | 권리 확인 전 상업 배포 금지 |

## HWP-6. 최초 합격 조건
합성 문서에서 본문 1개/표 1개 변경을 각각 별도 시험, 신규 파일 재열기, 원본 해시 동일, 수정 전후 객체·쪽/표 구조 비교, 실패 시 무변경. 반드시 프로그램 에디션/버전을 적은 시험 증거를 남긴다.
